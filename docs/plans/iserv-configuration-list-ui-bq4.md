## Scope and ownership

The ACTIVE GLOBAL ADMIN Connector collection keeps the current Tenant-selection navigation and configuration actions. Its trigger uses the primary collection-button treatment and concise “Create or configure” / “Erstellen oder Konfigurieren” label. Remove the long empty-configuration introduction for editable views while retaining necessary form guidance and the Tenant Admin managed-by-Global-Admin message. Display a Tenant UUID beside the name only when the complete Tenant collection contains the same name more than once, as on Product and Manufacturer pages.

The collection gains a case-insensitive literal Tenant-name substring search (`q`) and an optional exact enabled boolean filter (`enabled=true|false`). Conditions combine before server paging and total-count calculation; the existing name/UUID order remains stable. Search submission, enabled changes and reset return to page 0. The toolbar uses Connector-specific All connectors/Enabled only/Disabled only status choices (with German equivalents) and hides the Version column; the existing safe API summary retains version, and singleton version checking is unchanged. No issuer/client ID, mappings or Tenant UUID search is added. No schema migration is needed.
