The user performs login with a controlled account; no password is requested. A later functional change for the observed 403 needs its own reviewed decision.

No new public endpoint, database table, dependency, raw-payload logging or identity-policy change is authorized. Existing in-flight OIDC attempts must restart after a configuration change. Completion of local or simulated checks is not HUMAN ACCEPTANCE of real IServ interoperability.
